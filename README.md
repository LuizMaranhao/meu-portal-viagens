# 🌍 TravelGlobal - Portal de Viagens Premium

Este é um portal de viagens de alto padrão desenvolvido com **Next.js 16**, focado em oferecer uma experiência fluida de exploração de destinos turísticos. O projeto utiliza rotas dinâmicas para exibir detalhes de locais como Paris, Kyoto, Santorini e Machu Picchu.

## 🚀 Tecnologias e Ferramentas
* **Framework:** Next.js 16 (App Router)
* **Linguagem:** TypeScript
* **Estilização:** SASS (SCSS Modules) para um design profissional e modular.
* **Build Tool:** Turbopack para inicialização rápida do ambiente de desenvolvimento.
* **Icons & Fonts:** Design focado em azul marinho e dourado.

## 🛠️ Estrutura de Rotas
- `/`: Home com banner principal.
- `/destinos`: Listagem dinâmica de pacotes disponíveis.
- `/destinos/[id]`: Páginas individuais geradas via Dynamic Routes (Async Params).
